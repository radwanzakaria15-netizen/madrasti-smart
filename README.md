# مَدْرَسَتي الذكية — بداية مشروع المنصة

هذا مستودع بداية لتطبيق ويب عربي RTL باستخدام Next.js وSupabase وOpenAI.
يتضمن واجهة دخول الأستاذ، لوحة رئيسية، مادتي العربية والرياضيات، أنشطة أولية،
إدارة تلاميذ، تقارير، ومسارين خلفيين لتسجيل التقييم واستدعاء المساعد الذكي.

## مهم قبل الاستخدام
هذه ليست منصة منشورة أو جاهزة للإنتاج بعد. يلزم ربط مشروع Supabase، إنشاء حساب الأستاذ،
ضبط المتغيرات السرية، ثم النشر على استضافة. لا تضع مفاتيح API داخل كود المتصفح أو تشاركها في المحادثة.

## المتطلبات
- Node.js 20 أو أحدث
- حساب Supabase
- مفتاح OpenAI API لتفعيل المساعد التوليدي

## التشغيل
1. فك ضغط المشروع.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env.local` واملأ القيم.
4. في Supabase SQL Editor نفّذ محتوى `supabase/schema.sql`.
5. من Supabase Authentication أنشئ مستخدم الأستاذ:
   - البريد: `teacher@teacher.local` (أو عدّل صيغة البريد في `src/app/login/page.tsx`)
   - كلمة مرور قوية تختارها أنت.
6. أضف `NEXT_PUBLIC_TEACHER_USERNAME=teacher` إلى `.env.local`.
7. نفّذ `npm run dev` وافتح `http://localhost:3000`.

## إعدادات الأمان المطلوبة قبل نشر بيانات أطفال حقيقية
- غيّر سياسات RLS من السياسة العامة للمستخدم المسجل إلى ربط كل سجل بمعرّف الأستاذ/المؤسسة.
- أضف جدول profiles وجدول teachers وربط الطلاب بمؤسسة ومجموعة.
- لا تحفظ أسماء كاملة أو بيانات حساسة إلا عند الحاجة وبموافقة المؤسسة/الأولياء.
- أضف سجل تدقيق، نسخًا احتياطية، تحديد معدل الطلبات، والتحقق من المدخلات.
- أضف مصادقة متعددة العوامل للأستاذ وسياسة كلمات مرور قوية.
- اجعل إنشاء حسابات الطلاب أو رموزهم من لوحة الأستاذ فقط، مع رموز عشوائية قابلة للإلغاء.
- لا تسمح باستدعاء الذكاء الاصطناعي إلا من الخادم، مع حدود استخدام ومراقبة التكلفة.
- لا ترسل بيانات تعريفية للأطفال إلى مزود الذكاء الاصطناعي؛ استخدم معرفًا داخليًا ومعلومات تعليمية لازمة فقط.

## حدود النسخة الحالية
- الأنشطة تحتوي على أمثلة أولية ثابتة وليست منهجًا رسميًا كاملاً.
- صفحة الخط تعرض مسارًا مبدئيًا فقط؛ لم يتم بعد تنفيذ تحليل صورة الخط أو التتبع بالقلم.
- تسجيل المحاولات في هذه البداية لا يرتبط بعد بملف تلميذ محدد.
- المساعد الذكي يعمل عند إعداد مفتاح OpenAI، لكنه لا يشخّص اضطرابات تعلم ولا يستبدل حكم الأستاذ.
- يلزم إضافة اختبارات آلية، معالجة أخطاء شاملة، وتدقيق أمني قبل الاستخدام الفعلي.

## خارطة الطريق التالية
1. ربط كل نشاط بمعرف التلميذ ومجموعة الأستاذ.
2. بناء محرر كتابة على Canvas مع تتبع الحروف وتقييم أولي.
3. بناء مولد تمارين تكيفي مع مستويات صعوبة وقواعد انتقال يحددها الأستاذ.
4. ملفات فردية ورسوم تقدم زمنية.
5. إدارة محتوى الدروس والاختبارات من لوحة الأستاذ.
6. مراجعة حماية بيانات القاصرين ثم نشر نسخة تجريبية مغلقة.
